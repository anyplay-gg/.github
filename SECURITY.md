# Security

Report security problems privately, not in a public issue. Open the affected repository's **Security** tab, choose **Report a vulnerability** and include what is affected, how to reproduce it and what an attacker could do with it. Only the maintainers can read the report.

This covers every AnyPlay repository: [launcher](https://github.com/anyplaynet/launcher), [network](https://github.com/anyplaynet/network), [cloud](https://github.com/anyplaynet/cloud), [web](https://github.com/anyplaynet/web) and the [AnyPS5 fork](https://github.com/anyplaynet/AnyPS5). A problem in the cloud at anyplaynet.com goes to the cloud repository. If you are unsure which repository is affected, use [anyplaynet/network](https://github.com/anyplaynet/network/security/advisories/new).

Please do not attach game data to a report, and give us time to fix the problem before you publish it.
