# Security

Report security problems privately, not in a public issue. Open the affected repository's **Security** tab, choose **Report a vulnerability** and include what is affected, how to reproduce it and what an attacker could do with it. Only the maintainers can read the report.

If you are unsure which repository is affected, use [anyplaynet/network](https://github.com/anyplaynet/network/security/advisories/new).
